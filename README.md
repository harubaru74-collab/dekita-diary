# dekita-diary(できたこと日記 成長可視化)

はるかちゃんの「できたこと日記」を、今日・1週間前・1ヶ月前・1年前の同じ日付で並べて表示し、日々の成長を実感するためのプロジェクト。日記はClaudeとの対話でその日の出来事をまとめてもらいながら書く。

## このリポジトリの役割

- `diary/` … 日記本文(Markdown、原文のまま)。2026-08-16〜08-24分はGoogle Driveからの初期移行、それ以降はClaudeとの対話から直接保存
- `archive/shell.html` … 成長可視化ページのデザインの型
- `archive/BUILD.md` … ページの再生成手順・HTML変換ルール
- `ROUTINE.md` … 日々の運用方法(Claudeとの対話でまとめる→保存→サイト再公開、を1回の会話で完結させる)

## 公開範囲について

日記の内容が非常にプライベートなため、このリポジトリは Private、成長可視化ページも非公開のClaude Artifactとして運用している(GitHub Pagesは使わない)。詳細は [`ROUTINE.md`](./ROUTINE.md) の「公開・非公開について」を参照。

## 日々の使い方

Google DriveやRoutineは使わない。Claudeとの対話で今日の出来事をまとめてもらい、まとまったらそのままこのリポジトリへの保存とサイトの再公開まで同じ会話でお願いする。詳細は [`ROUTINE.md`](./ROUTINE.md) を参照。
